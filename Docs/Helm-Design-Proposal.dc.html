HELM · DESIGN SYSTEM v2 — PROPOSAL

An instrument, not an app.

Helm reads out your body the way a cockpit reads out an aircraft. The plan is the product; the numbers are the hero. This proposal keeps the OLED-black base already built at M0.4 and gives it a point of view: a single signature element (the Arc), a monospaced numeric voice, deliberate restraint with color, and a documented motion + haptic vocabulary so every build agent ships something that feels like one hand made it.

STATE-FIELD
The score is the wallpaper.

The top of the screen is a full-bleed field in today's state color, the number reversed out at poster scale. One glance from across the room tells you the day. Below it, flat full-width rows separated by hairlines, no boxes. Bold and immersive, and the field is the whole point rather than a tinted decoration.

Field color = state ramp. A depleted morning turns the wallpaper amber/red, so the warning is the environment, not a small badge.

BLUEPRINT
A measured instrument.

04 — MOTION + HAPTIC VOCABULARY

Haptics are a language, not decoration. You wanted more, so the vocabulary grows to twelve named patterns in four groups, each mapped to one class of moment. It stays a vocabulary, not noise: meaning is stable everywhere, celebration is spent rarely, and passive events never buzz. Motion and haptic fire together. Full spec + AHAP notes in HAPTICS.md.

SIGNATURE + READING · CORE LOOP · MILESTONES + CONFIRMATIONS · GUARDS + TEXTURE
READINESS REVEAL
signature

A rising swell that resolves on a soft crest as the arc lands on the score. The one haptic Cameron will learn to feel for each morning.

SET LOGGED
crisp

A single dry transient on checkmark. The core loop tap — must feel identical every rep so the hand trusts it.

REST DONE
urgent

Double pulse, fires even when suspended (via scheduled notification). Felt through a gym, not seen.

COACH ADJUST
soft

Two gentle bumps as a swap/reorder settles into the session. Confirms the coach touched the plan without stealing focus.

PR HIT
celebrate

A short ascending three-tap flourish, the only celebratory pattern. Rare by design — spend it only on a real record.

SELECTION
texture

The lightest tick under tab changes, numpad keys, and segment picks. System-generator, everywhere, so nav has grain.

REST COUNT-IN
anticipate

Three soft rising ticks in the last seconds of rest, so the next set is felt coming before the urgent rest-done pulse.

SESSION FINISHED
resolve

A firm transient that decays into a long settle when you finish the whole workout. Bigger than a set, smaller than a PR.

MEAL CONFIRMED
soft yes

One soft rounded bump when a photo-to-macro estimate is confirmed and written to Health. Quiet acknowledgement, no fanfare.

PHASE CHANGE
structural

An evenly-spaced triple that marks a structural shift: deload week begins, new mesocycle, or a phase change. The plan itself moved.

CLAMP REJECTED
firm no

A short sharp buzz when an adjustment or input hits a safe bound (RPE over cap, a clamp refusing an unsafe swap). Felt as resistance.

THRESHOLD INSIGHT
ambient

The faintest single swell when a silent insight surfaces in-app (a trend crossed a threshold). Optional, off by default, never interrupts.
